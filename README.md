# TWidgets
A Flutter library with useful widgets and utilities.

This project was initially designed to create a container that casts shadows onto semi-transparent surfaces
while preventing the back-face shadow rendering typical of standard HTML/CSS.

> [!IMPORTANT]
> This package is currently in early development and is not recommended for production environments.
